# 世界征召令首页文案与交互方案

## 1. 方案定位

本页面是一张可以操作的世界征召令。玩家先在主插画中选择种族，再从右侧职业卡中选择该种族对应的职业。选择完成后，点击“接受征召”，由印章和火漆动画确认选择，并进入职业检验。

文案原则：

- 外层公告正式、简短、容易理解。
- 任务名称使用可以直接阅读的文字标签，不使用只有图标的按钮。
- 详细任务目标在点击标签后展开。
- 戏谑内容只出现在任务详情的“工会备注”中，不影响主线危机的严肃感。
- 所有主要文字由网页渲染，不写死在背景图片中。

## 2. 主标题与种族

主标题：

> 世界征召令

副标题：

> 世界冒险者工会联合征募

主插画人物从左至右：

1. 人类
2. 精灵
3. 半兽人
4. 提夫林

原图中的矮人替换为半兽人。四名人物直接作为种族选择入口。

海报短文案：

> 人类 / 精灵 / 半兽人 / 提夫林

| --- | --- | --- | --- |

> 冒险者工会 / 城邦联盟 / 法师塔联合会 / 圣殿救援会 / 边境守望军

### 3.3 征召目的

主危机文案：

> 近月来，各地天空与古代传送门同时出现裂隙。城市失踪、季节错乱，魔物沿着断裂的道路进入现实。世界冒险者工会现面向各族征召人员，调查裂隙来源并维持各地秩序。

海报中不直接放入完整任务说明，只显示以下五个可点击文字标签：

1. 世界裂隙调查
2. 失踪城邦搜寻
3. 疑似救世主护送
4. 古龙危机谈判
5. 周期性岛屿调查

标签使用纸质索引签或印刷页签样式，保持直角或轻微圆角。选中后改变墨色、增加下划线或盖上小型工会印记，不使用现代发光胶囊样式。

### 3.4 如何接受征召

海报短文案：

1. 选择种族
2. 选择对应职业
3. 接受职业检验
4. 完成考核
5. 登记成为冒险者

可压缩显示为：

> 选种族 → 选职业 → 接受检验 → 完成考核 → 登记入会

### 3.5 报到说明

海报文案：

> 持本征召令至当地冒险者工会领取推荐印，再前往对应职业培训地点报到。

补充说明可以放在展开详情中：

> 推荐印仅限本人使用。种族与职业登记完成后不得私自涂改，如需变更，请重新接受职业检验。

## 4. 征召任务详情

### 4.1 世界裂隙调查

任务简介：

> 前往已发现的世界裂隙，确认其规模、稳定程度和另一侧环境，建立警戒范围并回收调查样本。

任务目标：

1. 找到裂隙并完成地图标记。
2. 判断裂隙属于稳定、扩张或移动状态。
3. 回收一份环境或魔力样本。
4. 建立临时警戒点并提交调查记录。

工会备注：

> 请勿把头伸进裂隙确认另一侧天气。此前已有三名实习员采用该方法，目前只回来两顶帽子。

### 4.2 失踪城邦搜寻

任务简介：

> 一座登记在册的城邦连同道路、居民和税务档案一起从地图上消失。调查其最后位置，确认城邦现状并恢复联络。

任务目标：

1. 追查城邦消失前的交通和魔力记录。
2. 找到城邦或确认其转移方向。
3. 核实居民、管理机构和基础设施状况。
4. 建立返程信标并带回城邦档案。

工会备注：

> 若当地官员坚称“我们只是集体搬家”，请要求出示迁址批文。无法出示批文的城邦，在行政意义上仍然属于失踪。

### 4.3 疑似救世主护送

任务简介：

> 护送一名被多份预言同时提及的旅人前往世界尽头。目标身份尚未完全确认，但已有多个敌对组织试图阻止其出发。

任务目标：

1. 核验目标身份和预言文件。
2. 制定安全路线并避开公开追捕。
3. 保证目标及关键物品完整抵达。
4. 将封存证明交给终点接收人。

工会备注：

> 目标可能没有战斗能力，但通常很有主意。请勿允许其在沿途每个村庄停下来接受支线委托，也不要让其临时组建第二支冒险队。

### 4.4 古龙危机谈判

任务简介：

> 一条古龙宣布将在近期毁灭数座城邦。任务重点不是击败古龙，而是查明诉求、建立停战窗口并争取修改行动日期。

任务目标：

1. 确认古龙身份、领地和正式诉求。
2. 建立不会立刻遭到吐息攻击的谈判渠道。
3. 提出赔偿、替代目标或延期方案。
4. 带回双方认可的书面或魔法契约。

工会备注：

> 能把末日从本周推迟到下季度，也算阶段性胜利。谈判期间请勿主动提及龙巢税、宝藏登记或历史欠款问题。

### 4.5 周期性岛屿调查

任务简介：

> 一座海岛每隔七天出现一次，并在日落后重新消失。调查岛上的遗迹、居民和时间异常，建立稳定的观测记录。

任务目标：

1. 推算岛屿下一次出现的时间和位置。
2. 登岛后建立定位信标和撤离计时。
3. 调查遗迹、居民及异常生物。
4. 在岛屿消失前撤离并带回记录。

工会备注：

> 错过撤离窗口的队员将自动转为下一期调查员，等待七天后统一接回。滞留期间不另计差旅补贴。

## 5. 任务标签交互规则

桌面端：

1. 五个任务标签显示在“征召目的”板块中。
2. 点击标签后，在征召令中央打开一张较大的任务附页。
3. 附页显示任务简介、四项目标和工会备注。
4. 点击其他标签时，附页原位切换内容。
5. 点击关闭按钮、附页外区域或按 Escape 键关闭附页。

移动端：

1. 五个标签改为纵向任务列表。
2. 点击任务后在该任务下方展开详情。
3. 同一时间只展开一个任务，避免页面过长。

可用性要求：

- 标签必须使用真实按钮元素，并具有明确的选中状态。
- 支持键盘切换、回车打开和 Escape 关闭。
- 展开后将焦点移动到任务标题，关闭后把焦点还给原标签。
- 任务标签只负责查看详情，不改变玩家的种族或职业选择。

## 6. 种族与职业卡联动

点击主插画中的种族人物后，右侧职业卡更新为：

| 种族 | 对应职业卡 |
| --- | --- |
| 人类 | 战士、吟游诗人、工匠、圣武士 |
| 精灵 | 游侠、法师、德鲁伊、潜行者 |
| 半兽人 | 野蛮人、战士、潜行者、牧师 |
| 提夫林 | 契约术士、潜行者、吟游诗人、血脉法师 |

职业卡采用四张叠放结构。玩家点击职业卡后，该卡向前移动并完整显示，其他卡留在后方。

职业命名与数据字段统一规则：

1. 对外固定使用“潜行者、契约术士、血脉法师”，不再显示“游荡者、术士、术法师”等旧称。
2. `targetId` 是职业路线的唯一内部标识，例如 `guild_rogue`、`guild_warlock`、`guild_sorcerer`。
3. 职业卡主标题必须由 `targetId` 映射为统一职业名，不能直接使用题库中的机构名称或风味称号。
4. 培训地点单独显示，例如“黑铁训练厅、斥候与机关处、异常契约审阅处、血脉术法厅”。
5. 旧题库中的 `classNameZh` 如果记录的是培训机构，只能作为培训地点使用，不能作为职业名。
6. 半兽人、提夫林旧题库使用 `name/description` 时，由应用适配层转换为职业简介，不得导致职业名称或介绍空白。
7. DND 评分引擎内部可以继续保留旧称作为兼容别名，但征召 UI、职业卡、试炼标题和结果摘要必须使用统一新名称。

### 6.1 种族与职业的选中状态

选中反馈必须同时作用于种族人物和职业卡，让玩家明确知道当前组合。

种族人物状态：

1. 悬停人物时，人物轮廓出现较弱的暖金色描边，提示该人物可以点击。
2. 选中种族后，人物在原位置轻微放大，并出现与该种族对应的动态印刷聚焦光；人物轮廓同时保留一圈较窄的暖金色或种族强调色硬边光。
3. 四个人物始终保持原有位置和占位尺寸。选中人物不能挤开、遮住或替换其他人物，也不能改变主插画区域高度。
4. 未选中的人物保持原位，可轻微降低亮度和饱和度，但仍需保持画面可读性。
5. 人物组下方设置一个固定高度的种族描述框。选中后只替换框内的种族名称和简短描述，不新增面板，不推动下方栏位。
6. 人物下方同时显示种族名称和“已选择”小印记，不能只依赖泛光表达状态。

职业卡状态：

1. 悬停职业卡时，卡片轻微抬起并出现较弱的边缘亮光。
2. 选中职业后，卡片移动到牌堆最前方，外围出现与种族人物一致的暖金色泛光。
3. 卡片左上角增加“已选择”印记，并显示职业名称和培训地点。
4. 其他职业卡保留在后方，不消失，玩家可以随时改选。

组合完成状态：

1. 只有种族和职业都已选中时，人物动态聚焦光与职业卡泛光才同时保持激活状态。
2. 人物动态聚焦光在组合完成后可以略微增强一次，再恢复稳定状态，用于提示选择已经完整。
3. “接受征召”按钮在组合完成后由不可用状态切换为可用状态。
4. 玩家改选种族时，原职业选择立即清空，右侧重新加载新种族对应的四张职业卡。
5. 玩家改选职业时，种族选择保持不变，只更新职业卡的选中状态。

确认状态：

1. 点击“接受征召”并完成盖章后，人物动态聚焦光和职业卡泛光停止变化，保留静态确认状态。
2. 人物和职业卡增加暗红色工会印记，表示组合已经锁定。
3. 动画播放期间禁止再次切换种族或职业。

可用性要求：

- 人物和职业卡使用真实按钮或等效的可聚焦控件。
- 键盘聚焦状态使用清晰的实线轮廓，与鼠标悬停状态区分。
- 选中控件设置 `aria-pressed="true"`，并向读屏工具提供“已选择”的状态文字。
- 减少动态效果模式下保留静态描边、泛光和“已选择”印记，不播放亮度脉冲或抬起动画。

### 6.2 种族人物动态印刷聚焦光

#### 6.2.1 视觉目标

种族人物被选中时，不使用普通柔光或现代霓虹泛光。选中效果应呈现为旧报纸上的“主角切入”：画面中的线条、色块或网点明确朝选中人物聚焦，并带有缓慢旋转、阶梯式明暗呼吸和轻微套色错位。

统一视觉名称：

> 双色套印半调主角放射光

英文检索与沟通用语：

> Dual-tone halftone protagonist radial burst

所有动态背景必须位于人物图层之后，不得遮挡人物面部、种族名称、职业卡或征召令正文。

人物选择采用原位强调，不改变页面布局：

1. 四个人物分别占据固定槽位，选中后槽位尺寸不变。
2. 人物建议使用 `transform: scale(1.03)` 至 `scale(1.06)` 轻微放大，变换原点位于底部中央。
3. 放大后的可视区域允许在人物槽位内预留，不得覆盖相邻人物。
4. 页面底部五个栏位在选择前后保持完全相同的位置、宽度和高度。

#### 6.2.2 种族与表现形式

| 种族 | 主要表现形式 | 主色 | 辅色 | 气质 |
| --- | --- | --- | --- | --- |
| 人类 | 放射日芒与硬边扇形色块 | 赭金 | 砖红 | 明朗、正式、具有征召海报感 |
| 精灵 | 放射日芒与硬边扇形色块 | 苔绿 | 淡金 | 自然、克制、轻盈但不柔弱 |
| 半兽人 | 同心半调涡旋与扩张网点 | 暗橄榄绿 | 铁黑，少量锈红 | 原始、强壮、具有压迫感 |
| 提夫林 | 同心半调涡旋与扩张网点 | 酒红 | 炭黑，少量暗金 | 神秘、危险、具有契约感 |

人类和精灵采用同一种“放射日芒”结构，但必须通过专色色板、射线疏密和旋转方向形成区分。半兽人和提夫林采用同一种“同心半调涡旋”结构，也必须通过网点大小、环带密度和强调色形成区分，不能只更换色相。

#### 6.2.3 人类与精灵：放射日芒

1. 放射中心锁定在人物胸口或头部，所有射线明确指向人物。
2. 射线之间使用两组交替扇形色块，颜色为清晰硬边，不使用平滑渐变。
3. 扇形色块内部叠加规则半调网点，边缘保留少量油墨破损和毛糙感。
4. 整个日芒层缓慢旋转，人物本身保持静止。
5. 人类的扇形更宽、更稳定；精灵的扇形更细、更疏朗，可使用相反的旋转方向。

#### 6.2.4 半兽人与提夫林：同心半调涡旋

1. 涡旋圆心锁定在人物胸口或头部，网点由中心向外逐渐增大。
2. 使用同心环、网点密度和局部旋转制造视觉吸附感，不使用高斯模糊形成黑洞效果。
3. 半兽人的网点更粗、更不规则，环带变化更有重量感。
4. 提夫林的网点更细密，可加入少量偏心或错位环带，产生不稳定的契约与魔法感。
5. 深色区域必须受控，选中效果不能压暗人物，也不能让五官和服装细节消失。

#### 6.2.5 统一印刷质感

四个种族虽然使用两种构图结构，但必须共享以下印刷语言：

1. 使用报纸半调网点、油墨颗粒、边缘缺墨和轻微纸张纹理。
2. 两个色调之间保持硬分隔，不使用连续渐变、透明雾、柔焦或 Bloom。
3. 强调色图层允许出现 `1px` 至 `2px` 的套色错位，但不能影响文字可读性。
4. 亮度变化表现为油墨浓淡或印刷曝光变化，不表现为电子灯光闪烁。
5. 参考图三只作为四个种族共用的颗粒破损与油墨边缘标准，不作为第三套选中结构。

#### 6.2.6 动画规则

| 动画 | 建议参数 | 要求 |
| --- | --- | --- |
| 背景旋转 | 每圈 `14s` 至 `20s` | 匀速、缓慢，人物与文字不旋转 |
| 明暗呼吸 | 每轮约 `2.2s` | 使用 `steps(4)` 或四个离散亮度关键帧 |
| 初次选中强调 | `300ms` 至 `450ms` | 快速增强一次，随后回落到稳定状态 |
| 套色错位 | `1px` 至 `2px` | 低频出现，不持续抖动 |
| 人物轻微放大 | `1.03` 至 `1.06` 倍 | 原位缩放，不影响其他人物布局 |
| 未选人物弱化 | 亮度与饱和度降低不超过 `15%` | 仍需看清人物与种族差异 |

呼吸顺序建议为“暗、中亮、强亮、中亮”。禁止使用平滑缩放模拟呼吸，避免画面产生现代霓虹或舞台灯效果。

同一时间只允许当前选中的一名种族人物播放完整聚焦动画。悬停其他人物时仅显示弱轮廓描边，避免多个旋转背景同时出现。

#### 6.2.7 实现约束

1. 不直接使用带水印的参考图片作为项目素材。
2. 放射日芒可使用 CSS 硬边 `conic-gradient`、网点遮罩和纸张纹理构成。
3. 同心半调涡旋可使用 `repeating-radial-gradient`、点阵遮罩或独立透明纹理层构成。
4. 旋转层、呼吸层、套色层和人物轮廓层应相互独立，便于调整强度和关闭动画。
5. 聚焦中心应根据每个人物在响应式布局中的实际位置计算，不能固定在整个页面中心。
6. 在 `prefers-reduced-motion: reduce` 下停止旋转、呼吸和套色变化，保留静态双色聚焦图案、人物硬边描边和“已选择”印记。
7. 人物放大必须使用不参与文档流重排的视觉变换，不能修改人物槽位宽度或网格列宽。
8. 种族描述框应预留固定高度，切换不同长度的文案时不得推动五个下方栏位。

#### 6.2.8 验收标准

1. 不看文字时，也能通过背景结构分辨人类/精灵组与半兽人/提夫林组。
2. 四个种族使用同一套纸张、网点和油墨质感，不得出现两套美术风格拼接感。
3. 选中后的第一视觉焦点必须落在人物，而不是旋转背景。
4. 动画连续观看十秒不刺眼、不造成文字闪烁，也不影响职业卡操作。
5. 桌面端和移动端的聚焦中心均与人物对齐，且不会裁掉主要射线或涡旋结构。
6. 深色种族效果下，人物面部、服装轮廓和种族特征仍然清楚可辨。
7. 连续切换四个种族时，人物、职业卡区域和五个下方栏位均不得发生位置跳动。
8. 种族描述框只显示当前种族的名称和一至两句短描述，不承担职业介绍或操作说明。

## 7. 接受征召与过渡

只有种族和职业都已选择时，“接受征召”按钮才可用。

确认流程：

1. 玩家点击“接受征召”。
2. 界面立即锁定种族和职业选择，防止重复提交。
3. 印章落下，火漆扩散并出现工会徽记。
4. 职业卡向右滑出，征召令向上收起。
5. 桌面清空后进入职业检验界面。

减少动态效果模式下，不播放印章落下和桌面清场动画，改为直接显示火漆确认状态并进入下一界面。

## 8. 图片拆分需求

原始图片不能直接承担全部交互，需要拆分或重制为：

1. 木桌与空白征召令背景，不包含标题、人物、职业卡和栏位文字。
2. 人类、精灵、半兽人、提夫林四张独立透明人物图，使用相同画布比例和脚底基线。
3. 四个人物对应的透明点击区域或轮廓遮罩。
4. 职业卡背面和可复用的职业卡透明边框，现有职业插画优先复用。
5. 工会印章、火漆印与工会徽记动画层。
6. 可平铺的纸张、半调网点与油墨颗粒纹理。
7. 网页文字层，包括标题、种族描述、五个板块和“接受征召”按钮。

原图中的矮人必须替换为半兽人。右侧原有卡牌应从背景中移除，改为根据已选种族动态生成的职业卡。标题、公告内容、种族描述、底部栏位文字和按钮均不得保留在背景图中。

人物选中光效不需要生成独立成图。人类与精灵的放射日芒、半兽人与提夫林的同心半调涡旋、人物轮廓光和日系漫画种族介绍框均由 HTML/CSS 实现。图片只提供透明人物、基础纹理、职业卡框、印章和火漆素材。
