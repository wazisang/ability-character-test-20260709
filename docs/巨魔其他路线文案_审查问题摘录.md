## 需要局部降刺激 / 避免现实冒犯的词句

以下不是要求洗白邪恶路线。巨魔可以危险、邪恶、黑暗、荒诞，但表达要落在奇幻语境，不要滑向现实精神污名、玩家羞辱或过度直白的自伤描写。

### 1. “神经质 / 疯子 / 疯癫”

位置：

- `physiqueChecks[4]` 某选项：
  - “眼神涣散但透着危险的神经质”
- `fighter_defense_choice` 或附近选项：
  - `npcReply`: “暗杀虫被你的神经质吓跑了。换防的队友看你的眼神像在看一个疯子。”
  - `triggerTags`: “神经质对话”
- `troll_transferred_naturalist.explanation`:
  - “像个疯癫的学者一样鼓捣孢子”
- `troll_absurd_scary.tableFunction`:
  - “难以预测的疯癫行为”

问题：

现实精神疾病污名化，和此前“降低刺激性、不现实冒犯”的要求冲突。

建议替换方向：

- “危险的恍惚感”
- “异常行为档案”
- “高危奇招”
- “古怪到让守夜人记进日志”
- “像被孢子谜题迷住的异变学者”
- “难以预测的怪异手段”

### 2. 见习结局过度羞辱玩家角色

位置：

- `troll_probation_slow_shield.title`: “迟缓的沙袋”
- `troll_probation_slow_shield.verdictLine`: “除了耐打你一无是处”
- `troll_probation_cowardly.verdictLine`: “你空有一身巨魔的皮肉，心里却住着一只受惊的兔子。”

问题：

见习失败可以尖刻，但这里太像系统羞辱玩家，而不是公会给出可演归宿。

建议替换方向：

- “迟缓的移动盾座”
- “你进攻迟缓，但这副身体仍能成为可靠的防线支点。”
- “你对战场代价看得太清楚，暂时只能以见习身份学习站稳。”
- 保留“怯战/迟缓/防守型见习”的角色缺陷，不要写成“废物评价”。

### 3. 自伤描写过直白

位置：

- `warlock_final_proof` 某选项：
  - “抓起祭坛上的献祭匕首疯狂捅向自己的心脏”
  - `npcReply`: “你自己的心脏也破了个大洞，奄奄一息。”
- `troll_accepted_warlock.playableFlaw`:
  - “时不时要通过自残来偿还债务。”

问题：

术士线允许血肉代价和危险交易，但这里过于直白地落到自伤动作。

建议替换方向：

- “把契约反噬引向自己的再生核心”
- “以一块靠近心口的再生血肉作抵押”
- “必须定期支付血肉利息来偿还债务”
- 重点写奇幻代价，不写现实化自伤动作。

### 4. “可憎的皮囊”建议改成偏见视角

位置：

- `mbtiFilters.NF.oneLine`: “甘愿让这副可憎的皮囊千疮百孔。”

问题：

如果是系统旁白，会默认认同“巨魔身体可憎”。此前要求是可以写文明偏见，但要明确这是外界凝视，不是系统立场。

建议替换：

- “甘愿让这副被世人畏惧的皮囊千疮百孔。”
- 或“甘愿让这副怪物外壳替身后的微光承受刀火。”

### 5. 现代/出戏词

位置：

- `troll_absurd_scary.playableFlaw`: “正常NPC跟你对话时必须先过一次意志豁免。”

问题：

建议替换：

- “多数公会书记员在给你登记前，都得先做一次意志豁免。”

### 6. 部分食人/吞食表达可以保留，但建议降低密度

位置：

- `druid_hunger_control.prompt`: “克制吃掉这只病患的冲动”

- `troll_blacklisted_butcher.verdictLine`: “试图生啖队友”

问题：

巨魔黑暗奇幻语境里可以保留野性饥饿，但连续直写“吃掉病患 / 幼狐 / 生啖队友”会让路线从邪恶奇幻滑向单一食人梗。

建议替换方向：

- “克制把病患视作补给的冲动”
- “把幼狐纳入猎物清单”
- “把队友也纳入饥饿本能的猎物范围”
