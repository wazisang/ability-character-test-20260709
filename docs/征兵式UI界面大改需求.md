# 征兵式 UI 界面大改需求

本文档用于指导另一个窗口对现有“能力角色仪”进行 UI / UX 大改。

目标不是把普通问卷换成奇幻皮肤，而是把整个体验改造成一个真正像 **西方奇幻征召处 / 冒险者雇佣大厅 / 阵营入队试炼** 的交互流程。

## 一句话定位

玩家不是来“做测试”的，而是走进一座冒险者征召大厅，选择血脉、投递志愿、接受体格鉴定与职业试炼，最后拿到一张带有录取结果、转岗命运和角色评价的冒险者档案。

## 当前问题

现有界面更像：

- 能力测试网站
- 问卷 + 小游戏 + 结果页
- DND 文案和立绘已经有气质，但流程仍然像测试工具

需要改成：

- 从第一屏就像“征兵 / 招募 / 入队”
- 玩家先选种族，再选征兵目标
- 每个职业试炼有不同视觉风格
- 内容页不再是普通题卡，而是“试炼场景”
- 失败、转岗、黑名单、见习都要有专属结果 UI

## 总体设计读法

Reading this as:

一个 DND 西方奇幻互动征召系统，受众是喜欢跑团、OC、自设、MBTI、职业测试的玩家。视觉语言应接近冒险者公会、佣兵契约、地城征召榜、阵营试炼，不要做成营销 landing page，也不要做成普通 SaaS 问卷。

建议设计参数：

- DESIGN_VARIANCE: 7
- MOTION_INTENSITY: 5
- VISUAL_DENSITY: 6

解释：

- 要有明显奇幻味和互动感
- 但不能乱成看不懂
- 页面需要承载种族、职业、属性、选项、反馈、进度等信息

## 核心流程

新流程如下：

1. 征召大厅首页
2. 选择种族
3. 根据种族选择征兵目标 / 职业方向
4. 种族体格鉴定
5. 职业试炼经历
6. 简易 MBTI 判断嵌入试炼
7. 征召判定 / 录取结果
8. 最终角色卡

不要让玩家感觉自己在填问卷。每一步都应该像在通过一个冒险者登记流程。

## 页面 1：征召大厅首页

### 目标

替换当前普通开始页。

第一眼要让玩家明白：

- 这里是冒险者征召处
- 玩家要投递自己的血脉和志愿
- 流程会生成角色档案

### 推荐视觉

场景方向：

- 地城入口旁的冒险者征召大厅
- 木质委托板
- 羊皮纸、蜡封、铁钉、印章
- 公会柜台、雇佣兵名册、火光
- 背景可以有暗色石墙、地图、旗帜、武器架

不要做：

- 纯居中大标题 + 两个按钮
- 现代问卷首页
- 太像游戏官网宣传页
- 泛用紫蓝渐变科技风

### 首页信息结构

顶部：

- 品牌：能力角色仪 / Adventurer Recruitment Office
- 当前状态：征召开放
- 轻量进度条或档案编号

主体：

- 大标题：今日征召开放
- 副标题：选择血脉，投递志愿，通过试炼，领取你的冒险者档案。
- 主按钮：开始登记
- 次按钮：随机投递
- 可选按钮：继续上次档案

下方露出下一屏内容：

- 种族档案卡预览
- 今日热门征兵目标
- 公会公告

### 文案占位示例

标题：

今日征召开放

说明：

请先登记你的血脉锚点。公会不会保证你被志愿单位录取，但会保证给你一份能上桌的命运安排。

按钮：

- 开始登记
- 随机投递一份简历

## 页面 2：种族选择

### 目标

种族不是装饰，而是整个流程的第一层身份锚点。

玩家选择种族后，会影响：

- 可选征兵目标
- 体格鉴定方式
- 试炼反馈
- 缺陷卡触发
- 最终评价口吻

### 种族列表

首批保留现有种族：

- 人类
- 精灵
- 暗精灵
- 矮人
- 半身人
- 侏儒
- 半兽人
- 提夫林
- 龙裔
- 哥利亚
- 巨魔
- 食人魔 / 巨人

### UI 结构

左侧或上方：

- 种族卡网格
- 每张卡像“血脉登记牌”
- 有种族名、标签、简短风险提示

右侧或下方：

- 当前选中种族详情
- 征兵官点评
- 体格鉴定重点
- 可能触发的缺陷卡提示
- 推荐征兵方向

### 种族卡状态

每张卡需要：

- 默认态
- 悬停态
- 选中态
- 稀有 / 特殊种族标识
- 暂未开放态

特殊种族不要每次都抢主角，但玩家手动选择时必须有仪式感。

### 巨魔样板视觉

巨魔卡应强调：

- 大型体格
- 再生
- 怪物感
- 力量与体质反差
- 空间适配困难

可以使用：

- 粗铁边框
- 暗绿色或腐蚀铜色点缀
- 裂纹纹理
- 大号印章：“怪物血脉登记”

不要把巨魔做成单纯愚蠢。

## 页面 3：种族职业征兵目标

### 目标

玩家选择“我想加入哪里”，但系统后续会根据试炼决定是否录取。

这一步要像选择投递志愿，而不是选择最终职业。

### UI 结构

标题：

选择你的征兵目标

说明：

志愿只代表你敲响了哪扇门，不代表那扇门会立刻为你打开。

卡片内容：

- 征兵目标名称
- 职业英文
- 招募口号
- 招募官
- 推荐强项
- 常见失败原因
- 隐藏路线提示

### 巨魔样板目标

巨魔首批显示：

1. 蛮子营地
2. 战士前线
3. 术士契约所
4. 德鲁伊异变环

每张卡要有不同视觉。

#### 蛮子营地

视觉：

- 兽皮
- 粗铁
- 战吼
- 斧痕
- 火堆

交互：

- 点击时像盖下粗暴的入营印章
- 动效可以是轻微震动、火星、红色冲击线

#### 战士前线

视觉：

- 军令
- 盾牌
- 阵线
- 旗帜
- 金属边框

交互：

- 点击像军章落下
- 进度条更规整

#### 术士契约所

视觉：

- 黑纸契约
- 墨水
- 细线
- 蜡封
- 眼睛或不可名状符号

交互：

- 点击像签下条款
- 选项反馈可以出现“契约批注”

#### 德鲁伊异变环

视觉：

- 树根
- 骨枝
- 绿光
- 自然法阵
- 异变纹理

交互：

- 点击像法阵回应
- 选项反馈像环形铭文展开

## 页面 4：种族体格鉴定

### 目标

替代普通体检感。

不要让玩家感觉在填身高体重表，而是接受“血脉体格鉴定”。

### UI 结构

标题：

血脉体格鉴定

模块：

- 体型锚点
- 承伤倾向
- 发力链条
- 恢复代价
- 社会目光

题目 UI 不要像普通选择题。

更合适的表现：

- 公会鉴定官的记录板
- 体格检定卷轴
- 地城现场测试
- 旁边显示征兵官短评
- 每次选择后盖一个小章或写一条批注

### 选项反馈

每次选项后立即出现 NPC 反馈。

反馈要短：

- 1 句吐槽
- 1 句判定

示例：

“鉴定官敲了敲你的肩骨：壳很响，问题是里面有没有把门撞开的东西。”

### 属性变化展示

不要直接显示“Str +2 / Con +1”作为主视觉。

可以做成：

- 小型徽记闪动
- 属性骰子轻亮
- 档案角落多一行批注

调试阶段可以有隐藏 Debug 面板显示具体分数。

## 页面 5：职业试炼内容界面

### 目标

这是整个新流程的核心。

不同职业试炼必须有明显风格区别，不能都是同一个题卡换标题。

### 通用结构

顶部：

- 当前种族
- 报名目标
- 试炼阶段
- 当前进度

主体：

- 场景标题
- 场景描述
- 4 个选择
- NPC / 考官反馈区

侧边或底部：

- 当前档案批注
- 倾向徽记
- 隐藏路线暗示

### 选项设计

每题 4 个选项应对应：

1. 职业正解
2. 高智商偏离
3. 危险邪恶
4. 荒诞奇招

UI 不要标明“正确答案”。  
但玩家选完后，反馈要让他知道自己正在偏向哪条命运线。

### 反馈表现

选择后不要立刻跳下一题。

应该先出现：

- 考官吐槽
- 公会批注
- 档案印章
- 某个路线轻微亮起

然后玩家点“继续试炼”。

## 不同试炼视觉风格

### 蛮子试炼

关键词：

- 火堆
- 战吼
- 斧痕
- 兽皮
- 粗鲁考官
- 简单但不愚蠢

布局：

- 大字号问题
- 选项像刻在木牌或盾牌上
- 反馈像考官在木板上粗暴打勾

颜色：

- 暗红
- 燃烧橙
- 黑铁
- 烟灰

动效：

- 点击有沉重冲击
- 印章落下
- 火星轻闪

### 战士试炼

关键词：

- 军纪
- 阵型
- 前线
- 盾墙
- 指挥官

布局：

- 更规整
- 选项像军令牌
- 反馈像战术图上的批示

颜色：

- 钢灰
- 军旗蓝
- 暗金
- 皮革棕

动效：

- 阵线推进
- 盾牌亮边
- 进度条像军令签发

### 术士试炼

关键词：

- 契约
- 条款
- 代价
- 低语
- 不可信的好处

布局：

- 选项像契约条款
- 鼠标悬停时可以出现细小批注
- 反馈像墨水自动写字

颜色：

- 墨黑
- 深紫
- 暗红
- 羊皮纸黄

动效：

- 墨迹蔓延
- 蜡封裂开
- 细线牵引

注意：

- 邪恶内容可以保留
- 但要保持奇幻契约语境，降低现实刺激性

### 德鲁伊试炼

关键词：

- 荒野
- 变形
- 异变
- 自然审判
- 怪物是否属于自然

布局：

- 选项像环形法阵或树根分叉
- 反馈像古树年轮浮现

颜色：

- 深绿
- 苔藓
- 骨白
- 微弱金光

动效：

- 藤蔓生长
- 法阵呼吸
- 叶影移动

## 页面 6：征召判定页

### 目标

不要直接进入普通结果页。

先给一个“判定仪式”：

- 公会审阅档案
- 招募官盖章
- 志愿单位回应
- 可能转岗

### 结果类型

1. 正式录取
2. 见习保留
3. 转岗推荐
4. 黑名单人才
5. 荒诞通过

每种结果要有不同 UI。

#### 正式录取

视觉：

- 录取印章
- 公会徽记
- 职业单位签名

语气：

- 你被接纳
- 但仍然有代价和职责

#### 见习保留

视觉：

- 半枚印章
- 临时木牌
- 见习徽记

语气：

- 你还不够稳
- 但角色很有成长线

#### 转岗推荐

视觉：

- 档案被转交到隔壁部门
- 第二枚印章盖过第一枚

语气：

- 你不是失败
- 你投错门了

#### 黑名单人才

视觉：

- 正规征召拒绝
- 暗处递来另一份契约
- 黑色边框或隐藏徽记

语气：

- 正规军不要你
- 但某些势力很感兴趣

#### 荒诞通过

视觉：

- 歪掉的印章
- 考官头疼批注
- 破损但有效的录取书

语气：

- 逻辑上不该过
- 但现场证据很难反驳

## 页面 7：最终角色卡

### 目标

结果页要从“资料堆叠”改成“征召档案”。

优先级：

1. 录取结果
2. 种族 + 职业
3. 角色打法
4. 可演缺陷
5. 六维属性
6. 体质鉴定
7. 缺陷卡
8. 详细日志

详细日志默认折叠。

### 推荐布局

首屏：

- 左侧：角色立绘 / 职业牌
- 右侧：录取书
  - 种族
  - 报名目标
  - 实际录取
  - 判定类型
  - 一句话评价

第二屏：

- 上桌打法
- 可演缺陷
- MBTI 演法
- 种族体质说明

第三屏：

- 六维属性
- 试炼记录
- 缺陷卡
- 给 DM 的摘要

## 全局组件需求

### 1. 征召印章

用于：

- 已选择种族
- 已选择征兵目标
- 题目完成
- 录取 / 拒绝 / 转岗

状态：

- pending
- passed
- failed
- transferred
- hidden_route

### 2. 档案批注

用于显示 NPC 反馈和系统判断。

样式：

- 像公会书记员写在档案边缘
- 或像契约边注

### 3. 路线暗示条

不要暴露精确分数，但可以显示倾向：

- 蛮子营地正在点头
- 法师塔正在偷看你的申请
- 契约所递来黑纸
- 前线军官把你加入候补名单

### 4. 隐藏 Debug 面板

开发阶段需要。

显示：

- 六维变化
- MBTI 倾向
- 职业适配度
- 结局判定条件
- 触发的缺陷卡

生产默认隐藏。

## 数据结构建议

UI 应尽量吃结构化数据，不要把文案写死在组件里。

建议数据分层：

```js
RACE_RECRUITMENT_DATA = {
  races: {},
  recruitTargets: {},
  physiqueChecks: {},
  trialSets: {},
  endings: {},
  uiThemes: {}
}
```

每个试炼目标有 theme：

```js
{
  "targetId": "barbarian_camp",
  "theme": {
    "layout": "campfire_board",
    "accent": "ember",
    "surface": "black_iron",
    "feedbackStyle": "wooden_judge_note",
    "stampStyle": "axe_mark"
  }
}
```

## MVP 范围

第一轮不要全量重做 12 种族 × 12 职业。

建议先实现：

1. 新征召大厅首页
2. 种族选择页
3. 巨魔种族完整流程
4. 巨魔 4 个征兵目标
5. 巨魔体格鉴定
6. 蛮子完整试炼 UI
7. 结局判定页
8. 最终角色卡重排

其他种族可以先显示为“登记中 / 待开放”，但 UI 架构必须支持后续接入。

## 视觉素材建议

优先使用现有：

- 立绘 assets/portraits
- 缺陷卡 assets/defect-cards

后续可以补：

- 种族卡背景图
- 征兵目标徽章
- 职业试炼背景图
- 录取书纹理
- 印章图形

如果没有图片，可以先用 CSS 纹理、边框、阴影、印章、图标做 MVP。

不要为了临时效果使用明显现代感 stock 图。

## 交互原则

1. 玩家每一步都知道自己在“登记 / 报名 / 受试 / 判定”。
2. 选择后必须有反馈，不要只是跳下一题。
3. 不要暴露所有分数，但要让玩家感到命运在变化。
4. 失败也要有仪式感。
5. 不同职业试炼必须有明显视觉差异。
6. 手机端必须能正常玩，选项不能挤爆。
7. 长文默认折叠，优先展示结论。

## 禁止项

- 不要做成普通 MBTI 测试页。
- 不要做成落地页。
- 不要在首页堆功能介绍。
- 不要所有试炼共用一张题卡皮肤。
- 不要用“属性 +2”作为玩家主反馈。
- 不要把失败写成玩家不行。
- 不要使用现实身体羞辱。
- 不要让巨魔等怪物种族全部变成低智笑话。
- 不要让文本信息在首屏互相抢注意力。

## 验收标准

实现后至少满足：

1. 第一屏看起来就是征召大厅，而不是问卷首页。
2. 玩家必须先选种族，再选征兵目标。
3. 巨魔选择后，页面明确发生风格变化。
4. 蛮子、战士、术士、德鲁伊四种试炼至少在视觉和反馈上有区别。
5. 体格鉴定不再像普通体检。
6. 每个选择后都有 NPC 反馈。
7. 失败有独立结局 UI，不是普通错误页。
8. 最终结果页优先展示录取结果和可玩角色，不再一上来堆满所有资料。
9. 桌面和手机都能顺畅完成流程。
10. 后续可以继续接入其他种族和职业，不需要推倒 UI 架构。

## 建议实施顺序

第一步：

搭建新流程状态机：

- raceSelect
- recruitTargetSelect
- physiqueCheck
- trial
- recruitmentJudgement
- result

第二步：
