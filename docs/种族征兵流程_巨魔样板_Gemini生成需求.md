# 种族征兵流程：巨魔样板线 Gemini 生成需求

本文档用于生成“种族选择 -> 种族职业征兵 -> 种族体格鉴定 -> 职业试炼经历 -> MBTI/六维评价 -> 结局”的文案数据。

本轮只做一个可跑通样板：**巨魔血脉**。

请只生成文本与结构化数据，不生成代码，不生成图片提示词。

## 目标

把现有能力测试从“普通问卷”改造成 DND 跑团风格的征兵流程。

玩家先选择种族，再选择该种族可报名的征兵目标，然后接受与种族、职业相关的体格鉴定和试炼事件。最终根据玩家的选择、体格、六维属性、MBTI 倾向和职业适配度，给出“录取 / 转岗 / 见习 / 黑名单 / 荒诞通过”等结局。

这不是严肃职业测试，而是一套“可验证、可游玩、可写成角色”的冒险者招募系统。

## 本轮样板

种族：巨魔血脉

种族关键词：

- 再生
- 怪物外壳
- 大型体格
- 吓人的存在感
- 力量与体质可能不匹配
- 低智不是必然，可以有“怪物直觉”“钝感智慧”“荒野生存逻辑”
- 适合写成被误解、被利用、被训练、被收编或主动加入冒险团的怪物血脉角色

核心测试职业目标：

1. 蛮子营地
2. 战士前线
3. 术士契约所
4. 德鲁伊异变环

其中“蛮子营地”是主样板，要生成完整题组。其他三个职业也要能在页面上显示为可选征兵目标，并提供简短试炼题组，方便后续扩展。

## 总体语气

风格要求：

- DND 跑团感
- 征兵处 / 冒险者公会 / 怪物佣兵登记处
- 带一点荒诞、吐槽、桌边笑点
- 但不是网络烂梗堆砌
- 角色评价要有功能性：能上桌、能扮演、能写成角色
- “失败”也要变成有趣的角色归宿，而不是羞辱玩家

允许：

- 黑暗幽默
- 邪恶路线
- 利益优先
- 怪物血脉带来的危险感
- NPC 讽刺和吐槽

避免：

- 现实身体羞辱
- 现实疾病羞辱
- 直接辱骂玩家本人
- 把“笨”写成现实智力攻击
- 完形填空式强行融合
- “你很适合某职业，因为你有某属性”这种机械句式

可以把“笨蛋自以为聪明的方法”写成游戏内喜剧，例如：

- “你提出了一个听起来像计划的东西，但考官发现那其实只是把门、怪物和队友都算作消耗品。”
- “你不是没脑子，你只是把脑子用在了如何更响地撞墙上。”
- “这份方案不适合法师塔，也不适合军部，但很适合在酒馆里被反复讲述。”

## 玩家流程

### 1. 种族选择页

生成巨魔种族卡文案。

需要字段：

- raceId: troll
- raceNameZh: 巨魔
- raceNameEn: Troll-blood
- title: 种族卡标题
- oneLine: 一句话吸引玩家
- bodyText: 80-140 字说明
- tags: 5-8 个标签
- warningText: 一句轻量提示，告诉玩家巨魔不是稳定强者，而是“体质、力量、体型、社会目光”共同塑造的角色
- recruiterQuote: 征兵官对巨魔报名者的欢迎词

### 2. 种族职业征兵目标

生成 4 张巨魔可报名职业目标卡。

职业目标：

1. barbarian_camp: 蛮子营地
2. fighter_line: 战士前线
3. warlock_contract: 术士契约所
4. druid_mutation_circle: 德鲁伊异变环

每张卡字段：

- targetId
- classNameZh
- classNameEn
- title
- oneLine
- recruiter
- recruitPitch: 60-100 字
- acceptedStyle: 录取后大概是什么打法
- likelyFailure: 常见失败原因
- hiddenRoute: 特殊路线，例如转岗、黑名单、契约路线、异变路线
- recommendedStats: 推荐强项数组，例如 ["str", "con"]
- riskTags: 3-5 个

注意：巨魔不能只绑定蛮子。巨魔可以成为高承伤战士、被契约利用的术士、研究自己再生血肉的德鲁伊异变者。

### 3. 巨魔体格鉴定

生成巨魔专属体格鉴定题。数量 5 道。

这些题用于替代普通人类 BMI 感的问法，不要问得像体检表。

题目方向：

1. 外壳与承伤：皮肉、骨架、再生速度
2. 力量与体质反差：看起来巨大，但是否真的能发力
3. 空间适配：地城窄门、低顶通道、桥梁承重
4. 恢复代价：再生是否消耗食物、睡眠、注意力或情绪
5. 社会目光：别人把你当怪物时，你如何处理

每题字段：

- id
- title
- scene: 80-140 字场景描述
- prompt: 一句提问
- options: 4 个选项

每个选项字段：

- id: A/B/C/D
- text
- npcReply: 选择后的 NPC 反馈，30-80 字
- scoreDelta:
  - str
  - dex
  - con
  - int
  - wis
  - cha
  每项取值 -2 到 +3，可以省略 0
- mbtiDelta:
  - I/E/N/S/T/F/J/P
  每项取值 -2 到 +2，可以省略 0
- affinityDelta:
  - barbarian
  - fighter
  - warlock
  - druid
  每项取值 -2 到 +3，可以省略 0
- alignmentDelta:
  - lawful
  - chaotic
  - good
  - self
  每项取值 -2 到 +2，可以省略 0
- triggerTags: 例如 ["巨体窄门", "力量空壳", "再生代价"]

### 4. 职业试炼题组

为 4 个征兵目标生成试炼题。

蛮子营地：7 道完整题  
战士前线：4 道题  
术士契约所：4 道题  
德鲁伊异变环：4 道题

每道题必须是一个具体场景，不要写成抽象心理测验。

#### 蛮子营地题目方向

1. 怪物挡路，队伍要进门
2. 你看起来很大，但实际力量不稳
3. 队友想制定复杂计划
4. 敌人嘲笑你只是会再生的肉盾
5. 你被命令守住窄门，但窄门会卡住你
6. 你狂暴后可能误伤队友
7. 最终考官让你证明“蛮子不是只有蛮力”

#### 战士前线题目方向

1. 阵线推进
2. 扛住冲击
3. 服从军令还是凭怪物直觉行动
4. 如何在队友害怕你时维持队形

#### 术士契约所题目方向

1. 有人想购买你的再生秘密
2. 契约要求你用痛苦换力量
3. 宗主承诺帮你摆脱怪物身份
4. 队友发现契约条款不干净

#### 德鲁伊异变环题目方向

1. 你的再生被视为自然异常
2. 荒野接纳你，城镇排斥你
3. 你需要控制饥饿、伤口、野性
4. 德鲁伊要求你证明自己不是污染源

每题字段同体格鉴定题：

- id
- targetId
- title
- scene
- prompt
- options

每个选项字段同上，另外增加：

- outcomeTone: one of ["合格", "偏离", "危险", "荒诞", "转岗"]
- branchHint: 该选项可能把玩家推向什么结局

## 选项设计要求

每道题 4 个选项必须有明显差异：

1. 职业正解：符合报名职业，但不一定道德完美
2. 高智商偏离：聪明，但不像当前职业，会触发吐槽或转岗
3. 危险邪恶：有用，但可能黑名单或契约路线
4. 荒诞奇招：离谱，但如果角色逻辑成立，可以喜剧通过

不要把“正确答案”写得太明显。玩家应该觉得每个选项都有戏。

## 失败与结局

生成 5 类结局模板，每类至少 4 条，适配巨魔语境。

结局类型：

1. accepted: 正式录取
2. probation: 见习保留
3. transferred: 转岗推荐
4. blacklisted: 正规单位拒绝，但黑暗路线盯上
5. absurdAccepted: 荒诞通过

每条结局字段：

- endingId
- endingType
- title
- verdictLine: 一句话判定
- explanation: 100-180 字，说明为什么是这个结局
- tableFunction: 上桌功能
- playableFlaw: 可演缺陷
- nextHook: 后续剧情钩子
- recommendedClass: 推荐职业
- rejectedClass: 如果有，被拒绝的报名职业
- tags

失败结局要求：

- 不要写“你失败了，你不行”
- 要写成“命运转岗 / 见习留用 / 被别处盯上 / 荒诞通过”
- 玩家最后仍然得到一张可玩的角色卡

## MBTI 与评价融合

为 4 个性格大组生成巨魔评价滤镜：

- NT: 理性、算计、结构、风险控制
- NF: 信念、保护、赎罪、情感重量
- SJ: 纪律、守则、职责、稳固防线
- SP: 临场、冲动、街头感、野性反应

每组字段：

- groupId
- title
- oneLine
- evaluationStyle: 80-140 字，说明这种性格如何演巨魔
- barbarianFlavor
- fighterFlavor
- warlockFlavor
- druidFlavor
- riskText

要求：不要只是“NT 巨魔很聪明”。要结合巨魔体格和职业选择。

示例方向：

- NT 巨魔蛮子：不是低智冲锋，而是计算自己能承受几次误伤，把身体当作战场资源。
- SJ 巨魔战士：用军规锁住怪物本能，像一堵会再生的城墙。
- NF 巨魔德鲁伊：把怪物外壳当成守护弱者的避难所。
- SP 巨魔蛮子：把疼痛、笑声和冲锋混成一种荒野节奏。

## 缺陷卡与体质触发关联

文案需要自然兼容以下缺陷卡，不要强行点名所有卡，但可以在 triggerTags 中标注。

优先关联：

- hollow_brute: 空壳蛮影，巨魔锚点 + 力量偏低
- heavy_bones: 重骨窄门，巨体锚点 + 空间适配困难
- overclocked_body: 过载肉身，高力量 + 低体质
- iron_stomach: 铁胃迟钝，高体质 + 低感知
- sleep_curse: 睡眠诅咒，恢复状态差

要求：

- 缺陷卡不是惩罚，是角色可演破绽。
- 体质低不是“现实身体差”，而是“血脉承载、再生代价、战场适配问题”。
- 力量低的巨魔不能写成废物，要写成“外壳很吓人，但发力链条、技巧、胆气或旧伤有问题”。

## 字段细则

scoreDelta、mbtiDelta、affinityDelta、alignmentDelta 中值为 0 的字段可以省略。

所有 id 使用英文小写和下划线。

所有显示文案使用中文。

每个选项必须有 npcReply。

每个题目的 4 个选项不要重复同一种思路。

每段 explanation 不要超过 180 字。

## 质量验收标准

生成结果需要满足：

1. 巨魔不是单调蛮力模板，有“体质反差、空间代价、社会目光、再生成本”。
2. 蛮子营地题组最好玩，能体现“玩家报名蛮子，但可能被转岗”的机制。
3. 每个选项都有明确计分倾向，能接入六维 / MBTI / 职业适配。
4. NPC 吐槽有趣，但不攻击现实玩家。
5. 失败结局仍然能得到角色卡。
6. 文案能直接放进网页，不需要再大幅清洗。
7. 不要出现“根据你的选择，你是一个……”这类测试腔。
8. 不要出现“该角色具有较高的力量属性，因此适合……”这类机器评价。
9. 不要把邪恶路线洗白，但降低现实刺激性，让它保持奇幻语境。
10. 不要把所有巨魔都写成笨蛋。可以笨，可以野，可以钝，但必须能成角色。
