## 接入入口

不要手工硬塞图片路径到业务逻辑里。当前接入链路是：

1. `assets/recruitment/image_manifest.json` 记录所有槽位、状态、文件、prompt。
2. `data/race-recruitment-assets.js` 由生成脚本写入，暴露 `window.RACE_RECRUITMENT_ASSETS`。
3. `index.html` 在 `data/race-recruitment-troll.js` 前加载 `data/race-recruitment-assets.js`。
4. `app.js` 通过 `getRaceArt`、`getTargetArt`、`getQuestionArt`、`getEndingArt` 一对一取图。
5. `styles.css` 负责固定图片比例和遮罩：种族卡 `2 / 3`，其他 P0 场景图 `16 / 9`。

## 续生成命令

每次只生成一张，成功后脚本会自动保存源图、裁切预览图、更新 manifest、更新 `data/race-recruitment-assets.js`。

```powershell
node tmp/recruitment/generate_recruitment_asset_one.js troll_physique_04_regeneration_cost
node tmp/recruitment/generate_recruitment_asset_one.js troll_physique_05_tavern_stares
node tmp/recruitment/generate_recruitment_asset_one.js troll_ending_accepted
node tmp/recruitment/generate_recruitment_asset_one.js troll_ending_probation
node tmp/recruitment/generate_recruitment_asset_one.js troll_ending_transferred
node tmp/recruitment/generate_recruitment_asset_one.js troll_ending_blacklisted
node tmp/recruitment/generate_recruitment_asset_one.js troll_ending_absurdAccepted
```

如果网页端已经生成成功但脚本在保存前中断，使用：

```powershell
node tmp/recruitment/generate_recruitment_asset_one.js <assetId> --extract-existing
```

## 风格统一规则

### 种族卡

种族卡已经全部生成完成。后续如果返工，必须继续使用脚本中的 `RACE_CARD_STYLE_PREFIX`：

```text
DND fantasy race card illustration, portrait-orientation 2:3 canvas, tall vertical tarot card image, full card visible from top to bottom, cohesive defect-card series, ornate dark bronze tarot border, dark parchment background, subtle arcane frame, single centered subject, cinematic tabletop RPG character concept art, dramatic but clean lighting, clear readable silhouette.
```

硬性规则：

- 输出比例：2:3。
- 裁切尺寸：720x1080。
- 不要改回 4:5。
- 不要使用“race registration card / dossier card / wax-seal / iron-rivet / blank nameplate”这类会让边框漂移的提示词。
- 不要生成个人 CG、头像、半身立绘、角色设定图。
- 参考成品：`assets/defect-cards/generated/*.webp` 和 `assets/recruitment/generated/race_*_card-preview.webp`。

### 16:9 场景图

体格题图、目标图、判定结果图继续使用脚本中的 `STYLE_PREFIX`：

```text
Western fantasy tabletop RPG illustration, cinematic painterly realism, adventurer guild recruitment atmosphere, strong readable silhouette, detailed environment props, dramatic torchlight, parchment and iron texture, grounded dark fantasy, high detail, professional game concept art, cohesive recruitment asset series.
```

硬性规则：

- 输出比例：16:9。
- 裁切尺寸：1536x864，首页 hero 例外为 1920x1080。
- 不要出现文字、水印、logo、现代 UI、赛博霓虹、过度萌化、血腥特写。
- 画面必须适合被网页遮罩压暗后作为题目/判定场景图使用。

## 续跑后验收

每生成一张后至少跑：

```powershell
node --check app.js
node --check data/race-recruitment-assets.js
node --check tmp/recruitment/generate_recruitment_asset_one.js
```

并检查：

- `assets/recruitment/image_manifest.json` 的 `readyCount` 是否增加。
- `data/race-recruitment-assets.js` 是否出现对应 `questions` 或 `endings` 映射。
- 本地文件是否存在且尺寸正确。
- 页面缺图时仍能 fallback，不出现空白或控制台错误。
