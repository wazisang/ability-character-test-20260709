# 世界征召令界面线框草图

## 1. 使用说明

本文档用于确认页面结构、交互顺序和信息层级，不代表最终美术效果。

- `[按钮]`：可以点击的操作。
- `(人物)`：可以点击的种族人物。
- `{卡牌}`：可以点击的职业卡。
- `>>>`：放射日芒或视觉指向线。
- `(( ))`：同心半调涡旋。
- `*`：当前选中状态。
- 页面主文字由 HTML/CSS 渲染，不写入背景图片。
- 四个人物始终位于固定槽位，选中时只在原位轻微放大和发光，不参与布局重排。
- 人物组下方的种族描述框和页面底部五个栏位始终保留固定占位。

完整流程：

```text
初始征召令
    |
    v
选择种族 -------> 查看征召任务详情
    |
    v
选择该种族职业
    |
    v
接受征召并盖章
    |
    v
桌面清场过渡
    |
    v
进入职业检验
```

## 2. 界面一：初始征召令

目标：让玩家先理解世界危机，再从四个人物中选择种族。

```text
+----------------------------------------------------------------------------+
|                            世 界 征 召 令                                   |
|                     世界冒险者工会联合征募                                 |
|                                                                            |
|  +--------------------------------------------------+  +----------------+  |
|  |                  主人物插画区域                  |  |   对应职业卡   |  |
|  |                                                  |  |                |  |
|  |   (人类)    (精灵)    (半兽人)    (提夫林)       |  |  请先选择种族  |  |
|  |                                                  |  |                |  |
|  |  +--------------------------------------------+  |  |  {背面卡牌}    |  |
|  |  | 种族描述：请选择一名人物                   |  |  |                |  |
|  |  +--------------------------------------------+  |  |                |  |
|  +--------------------------------------------------+  +----------------+  |
|                                                                            |
|  [今日招募] [合作单位] [征召目的] [如何接受] [报到说明]                    |
|                                                                            |
|  世界裂隙调查 / 失踪城邦搜寻 / 疑似救世主护送 / 古龙危机谈判 / 岛屿调查   |
|                                                                            |
|                         [接受征召：尚不可用]                               |
+----------------------------------------------------------------------------+
```

交互状态：

1. 四名人物均可点击，悬停时只出现弱轮廓描边。
2. 右侧职业卡处于封闭或背面状态。
3. “接受征召”按钮不可用。
4. 点击征召目的标签，可以打开任务详情，但不会改变种族选择。
5. 种族描述框和下方五个栏位已经占位，后续选择不会改变其位置。

## 3. 界面二：人类或精灵已选中

目标：使用放射日芒明确表现人类或精灵被选中，并展开对应职业。

```text
+----------------------------------------------------------------------------+
|                            世 界 征 召 令                                   |
|                                                                            |
|  +--------------------------------------------------+  +----------------+  |
|  |              双色半调放射日芒                    |  |  人类对应职业  |  |
|  |       >>>>>                                     |  |                |  |
|  |      (*人类*)   (精灵)   (半兽人)   (提夫林)     |  |  {战士}        |  |
|  |                                                  |  |    {吟游诗人}  |  |
|  |  +--------------------------------------------+  |  |      {工匠}    |  |
|  |  | 人类：适应力强，善于在变化中建立秩序。     |  |  |        {圣武士}|
|  |  +--------------------------------------------+  |  |                |  |
|  +--------------------------------------------------+  +----------------+  |
|                                                                            |
|  [今日招募] [合作单位] [征召目的] [如何接受] [报到说明]                    |
|                                                                            |
|                         [接受征召：尚不可用]                               |
+----------------------------------------------------------------------------+
```

视觉规则：

1. 放射中心锁定在选中人物的胸口或头部。
2. 日芒缓慢旋转，双色扇形以硬边分隔。
3. 人类使用赭金与砖红；精灵使用苔绿与淡金。
4. 选中人物只在原位放大约 `3%` 至 `6%`，其他三名人物的位置和尺寸不变。
5. 未选人物可降低不超过 `15%` 的亮度和饱和度。
6. 人物下方固定描述框只切换种族名称和一至两句简短描述。
7. 右侧显示当前种族的四张叠放职业卡，下方五个栏位框架不变。


视觉规则：

2. 网点环缓慢旋转，并以四档油墨浓度呼吸变化。
3. 半兽人使用暗橄榄绿、铁黑与少量锈红。
4. 提夫林使用酒红、炭黑与少量暗金。
5. 选中人物只在原位置轻微放大，不能挤动或遮挡其他人物。
6. 深色背景不能遮住人物面部和服装细节。
7. 描述框与下方五个栏位始终保持固定位置和尺寸。

## 5. 界面四：种族与职业均已选择

目标：清楚展示“种族 + 职业”的最终组合，并允许玩家确认征召。

```text
+----------------------------------------------------------------------------+
|                            世 界 征 召 令                                   |
|                                                                            |
|  +--------------------------------------------------+  +----------------+  |
|  |       >>>>>                                      |  |   职业牌堆     |  |

|  |  +--------------------------------------------+  |  |      {工匠}    |  |
|  |  | 人类：适应力强，善于在变化中建立秩序。     |  |  |        {圣武士}|
|  |  +--------------------------------------------+  |  |  {*战士*}      |  |
|  +--------------------------------------------------+  |                |  |
|                                                      +----------------+  |
|  职业简介：接受基础战斗、队形协作与装备使用训练。                        |
|  培训地点：当地战士学院或冒险者工会训练场。                              |
|                                                                            |
|  [今日招募] [合作单位] [征召目的] [如何接受] [报到说明]                    |
|                                                                            |
|                           [ 接受征召 ]                                     |
+----------------------------------------------------------------------------+
```

交互状态：

1. 选中职业卡移动到牌堆最前方，完整显示职业名和培训地点。
2. 人物聚焦光与职业卡描边同时增强一次，然后恢复稳定状态。
3. “接受征召”按钮由不可用变为可用。
4. 改选种族时清空职业；改选职业时保留当前种族。
5. 组合完成后人物槽位、种族描述框和五个下方栏位仍然不移动。

```text
|                    |       征召登记已确认       |                          |
```

## 10. 移动端布局参考

移动端不强行保留桌面端左右结构，改为由上到下的单列流程。

```text
+------------------------------+
|        世界征召令            |
|  世界冒险者工会联合征募      |
+------------------------------+
|                              |
|     两行人物选择区           |
|                              |
|   (人类)       (精灵)        |
|   (半兽人)     (提夫林)      |
|                              |
+------------------------------+
| 当前种族：人类 [已选择]      |
| 简短种族介绍                 |
+------------------------------+
| 对应职业                     |
|                              |
| {战士} {吟游诗人}            |
| {工匠} {圣武士}              |
+------------------------------+
| [今日招募] [合作单位]        |
| [征召目的] [如何接受]        |
| [报到说明]                   |
+------------------------------+
|        [接受征召]            |
```

移动端规则：

1. 人物使用稳定的两列网格，选择时不能改变人物区域高度。
2. 选中人物只在格内轻微放大；放射日芒或涡旋也限制在单个人物格内，不能挤动或覆盖相邻人物。
3. 职业卡由叠放改为两列卡片，选中卡不改变整体网格宽度。
4. 种族描述框预留固定高度，切换内容时不能推动职业卡和信息板块。
5. 五个信息板块使用可展开标题，同一时间只展开一个，标题框架始终保留。
6. “接受征召”可固定在页面底部，但不能遮挡职业卡和正文。

## 12. 固定 UI 布局方案

本节为世界征召令桌面端的固定布局。人物选择前后不重排页面，不改变人物、职业卡或底部栏位的占位尺寸。

### 12.1 整体布局

```text
+--------------------------------------------------------------------------------+
|                                世界征召令                                      |
|                         世界冒险者工会联合征募                                 |
+---------------------------------------------------------+----------------------+
|                                                         |                      |
|                  固定人物展示区域                       |    职业卡牌区域      |
|                                                         |                      |
|     (人类)       (精灵)       (半兽人)      (提夫林)    |      {职业卡 4}      |
|                                                         |        {职业卡 3}    |
|        选中人物只原位放大 3% 至 6% 并发光              |          {职业卡 2}  |
|                                                         |            {职业卡 1}|
|          ▼ 指针移动到当前选中人物下方                  |                      |
|  +---------------------------------------------------+  |                      |
|  | / 人类 HUMAN /                                   |  |                      |
|  |  适应力强，职业道路广，善于在变化中建立秩序。    |  |                      |
|  +---------------------------------------------------+  |                      |
+---------------------------------------------------------+----------------------+
| [今日招募] | [合作单位] | [征召目的] | [如何接受] | [报到说明]               |
+--------------------------------------------------------------------------------+
| 世界裂隙调查 | 失踪城邦搜寻 | 救世主护送 | 古龙谈判 | 岛屿调查               |
+--------------------------------------------------------------------------------+
|                               [ 接受征召 ]                                  印章 |
+--------------------------------------------------------------------------------+
```

整体区域建议：

| 区域 | 建议比例或尺寸 | 布局要求 |
| --- | --- | --- |
| 页面标题 | 页面高度的 `8%` 至 `12%` | 标题与副标题居中，不随选择变化 |
| 主人物区域 | 主内容宽度的 `70%` 至 `74%` | 四个人物使用固定槽位 |
| 职业卡区域 | 主内容宽度的 `26%` 至 `30%` | 始终预留四张叠放职业卡空间 |
| 人物展示 | 主人物区域高度的 `68%` 至 `74%` | 人物脚底对齐，头顶预留放大空间 |
| 种族描述框 | 高度 `96px` 至 `112px` | 固定高度，文字变化不能推动下方内容 |
| 五个栏位 | 固定一行 | 选择前后位置、宽度和高度不变 |
| 接受征召区 | 固定底部操作区 | 按钮和印章位置不随正文高度变化 |

### 12.2 日系漫画种族介绍框

种族描述采用日系漫画人物介绍框，不使用普通圆角对话气泡，也不表现为角色正在说话。

```text
                        指向当前选中人物
                                 ▼
+------------------------------------------------------------------+
| / 人类 HUMAN /      [今日征召]                                   |
|------------------------------------------------------------------|
| 适应力强，职业道路广，善于在变化中建立秩序。                     |
| 在大多数组织中都能找到适合自己的位置。                           |
+------------------------------------------------------------------+
```

介绍框内部布局：

| 元素 | 位置 | 要求 |
| --- | --- | --- |
| 指向尖角 | 框体上沿 | 横向移动并指向当前人物，不改变框体位置 |
| 种族名称 | 左上或左侧 `25%` 区域 | 使用较大字号和斜切墨块，可附英文副名 |
| 征召状态 | 名称右侧 | 使用小型印章或矩形标签，不使用圆角胶囊 |
| 简短描述 | 右侧或下方 `75%` 区域 | 只显示一至两句，不超过两行 |
| 半调底纹 | 整个框体底层 | 使用低对比网点、油墨颗粒和纸张纹理 |
| 种族专色 | 左侧边条、名称条或局部底纹 | 不覆盖正文，不降低文字对比度 |

指针位置对应四个人物固定槽位：

| 种族 | 指针水平位置 |
| --- | --- |
| 人类 | `12.5%` |
| 精灵 | `37.5%` |
| 半兽人 | `62.5%` |
| 提夫林 | `87.5%` |

视觉组合参考：

1. 信息布局参考日系少年漫画中的人物资料卡：大名称、小分类标签、简短正文。
2. 名称条采用斜切漫画分镜结构，边缘允许轻微油墨毛糙和套色错位。
3. 外框使用不完全规则的黑色墨线，但不能采用大面积纯黑背景。
4. 框体底色继续使用征召令的米白纸张，确保与页面统一。
5. 不在介绍框内重复放置人物头像，因为完整人物已经位于上方。

### 12.3 选择前后状态

```text
选择前： (人类)   (精灵)   (半兽人)   (提夫林)

选择后：(*人类*)  (精灵)   (半兽人)   (提夫林)
           ↑
       原位轻微放大
       背后印刷光旋转
       介绍框指针移到人类下方
       其他人物和所有栏位保持不动
```

选择行为要求：

1. 人物放大使用 `transform`，不能修改网格列宽或人物槽位宽度。
2. 人物建议放大 `1.03` 至 `1.06` 倍，变换原点位于底部中央。
3. 介绍框只更新指针位置、种族名称、种族专色和描述文字。
4. 描述框切换时不改变高度，不播放整体滑入或弹出动画。
5. 右侧职业卡只替换内容，不改变职业卡区域尺寸。
6. 页面底部五个栏位始终保持同一套框架和位置。
7. 连续切换四个种族时，页面不得出现横向或纵向跳动。

3. 删除图片中写死的右侧职业卡，职业卡改为网页动态牌堆。
4. 删除图片中写死的五个底部板块文字、任务标签和操作按钮，只保留空白纸张版面。

### 13.3 四名人物拆层要求

1. 四名人物必须分别输出为透明背景图片，不能继续合并在一张插画中。
2. 四张人物图使用相同画布比例、脚底基线、视角、光源和印刷颗粒密度。
3. 人物四周预留至少 `6%` 的透明安全区，保证放大 `1.03` 至 `1.06` 倍时不会裁切。
4. 人物姿态应便于横向并列，武器、披风、角和耳朵不能大幅侵入相邻槽位。
5. 人类与精灵保持较明朗、秩序化的英雄剪影；半兽人与提夫林可以更有压迫感，但不得过暗。
6. 半兽人必须具有明显的獠牙、强壮体格或部族装备特征，不能继续呈现为矮人轮廓。
7. 提夫林必须保留角、尾部或魔裔服装特征，与精灵的尖耳轮廓明显区分。
8. 图片中不得包含种族名、介绍文字、边框、按钮、发光效果或水印。

### 13.4 不需要生成成图片的内容

以下内容必须由 HTML/CSS 或网页动画实现，不应写死在图片中：

1. “世界征召令”标题、副标题和全部公告文字。
2. 日系漫画种族介绍框、移动指针、种族名称和简短描述。
3. 人类与精灵的双色半调放射日芒。
4. 半兽人与提夫林的同心半调涡旋。
5. 人物轮廓光、轻微放大、明暗呼吸和套色错位。
6. 五个底部栏位、任务标签和任务详情附页。
7. 职业名称、培训地点、“已选择”印记和“接受征召”按钮。

### 13.5 图片验收标准

1. 四名人物并排时脚底对齐，视觉体量合理，切换选择时不会出现明显大小跳变。
2. 人物面部、服装和种族特征在正常页面尺寸下清晰可辨。
3. 图片整体不偏暗，不依赖后期大幅提高亮度才能使用。
4. 四名人物共享同一套旧报纸、半调网点和油墨颗粒风格。
5. 不同种族具有明确剪影和配色差异，缩小后仍能快速辨认。
6. 背景底图保留足够空白区域，网页文字与职业卡可以安全覆盖。
7. 所有素材无水印、无生成乱码、无多余文字、无错误肢体和穿模。
8. 桌面端和移动端裁切后，人物头部、武器和种族关键特征仍然完整。
