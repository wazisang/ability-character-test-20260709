# Gemini 文案优化需求包

用途：请 Gemini 帮本项目优化网站文案、题目说明、选择题、结果页、职业候选、人格滤镜与 OC/TRPG 角色参考文本。

重要限制：本需求包只做文字内容优化，不处理视觉资源制作方案、素材管理方案或模型参数。

## 1. 项目定位

这是一个线上互动能力测试原型，用 DND 六维属性、MBTI 自填/推断、善恶九宫格、现实体质校准与小游戏表现，把用户本人转译成一套可用于 OC、自设、跑团角色创作的娱乐化能力档案。

它不是医学诊断、心理诊断、职业测评或严肃人格判断。文案要保留娱乐感和角色创作感，同时让用户觉得结果有一定参考价值。

## 2. 核心原则

1. 能力属性驱动，不是人格标签驱动。
2. DND 职业候选必须根据六维属性、小游戏表现和结果组合计算，不能被 MBTI 固定绑定。
3. MBTI 只作为“表达风格 / 决策风格 / 社交滤镜”，用于解释同一个职业候选在不同人格下会呈现怎样的气质。
4. ESFP 可以是法师、战士、游侠；INTJ 也可以是战士、圣武士、吟游诗人。只要属性表现支持，职业候选就应该开放。
5. 善恶九宫格用于补充价值观与行动边界，不要写成道德审判。
6. 文案要适合网站直接使用：短标题有冲击力，说明文字清晰，结果描述有角色档案感。
7. 不要使用“你就是”“你必然”“你天生只能”这类定死用户的措辞，优先使用“倾向于”“更像是”“在当前测试中表现为”。

## 3. 禁止输出内容

请不要输出以下内容：

- 视觉资源制作方案
- 素材目录或资源管理方案
- 外部生成工具调用方案
- 模型参数或生成参数
- 医学诊断、心理诊断、临床建议
- 把 MBTI 和 DND 职业一一绑定的固定表

## 4. 网站整体语气

希望风格介于“游戏角色档案”“开放测试报告”“跑团建卡参考”之间。

文案可以更有戏剧感，但不要空泛中二；可以有世界观味道，但必须让普通用户能看懂；可以夸张一点，但不要让用户觉得被冒犯或被贴死标签。

推荐语气关键词：

- 神秘感
- 游戏化
- 可解释
- 有一点仪式感
- 像角色卡而不是体检表
- 像开放测试而不是严肃考试

## 6. 六维属性与小游戏说明

### 6.1 力量 STR

模块：躯体爆发力、负重续航。

小游戏：

- 破障三段式：连续点击击破障碍，分低/中/高三级波次。
- 负重稳定条：长按维持力量区间，偏离过久扣分。

需要强调：

- STR 不只等于肌肉，也包括爆发、施力稳定、短时推进力。
- 结果可用于判断角色是否适合冲锋、压制、近战强攻或力量型行动。

### 6.2 敏捷 DEX

模块：躯体机动反应、精细手工操控。

小游戏：

- 反应阶梯：随机目标出现，按低/中/高难度逐级测试反应速度和准确率。
- 精准画线：沿曲线临摹，判断手部稳定与误差控制。
- Dodge Show 走位：操控角色躲避连续障碍，判断空间走位、节奏反应、临场修正。

需要强调：

- DEX 包含闪避、手眼协调、细微控制，而不是单纯“手速快”。
- 对手作、乐器、潜行、射击、杂技型角色都有参考价值。

### 6.3 体质 CON

模块：现实校准、生理抗性、续航承受。

小游戏与校准：

- 现实体质校准：年龄、身高、体重、体脂率、运动、睡眠、健康问题自评。
- 节奏续航：持续匀速操作，检测稳定性和疲劳后的波动。
- 压力稳定条：干扰条件下完成简单任务，检测抗干扰与持续执行。

需要强调：

- CON 是娱乐化体质参考，不是健康结论。
- 结果应写成“角色建卡参考”，例如耐久、恢复、抗压、负面状态承受。

### 6.4 智力 INT

模块：记忆力、抽象思维、逻辑推演、长判断能力。

小游戏：

- 记忆阶梯：短时记忆数字、图形或符号序列，难度递增。
- 抽象归纳：从符号、图形或概念中寻找规则。
- 长判断推理案：多线索推理，判断隐藏因果、时间顺序或真正矛盾点。

需要强调：

- INT 不等于学历或知识储备。
- 它包含抽象、记忆、结构化分析、长期判断、拆解复杂信息的能力。
- 推理题不能太像小学题，要有角色场景、线索迷惑和判断成本。

### 6.5 感知 WIS

模块：精微感官、判断力、专注力、环境觉察。

小游戏：

- 色彩阶梯：多轮相近色块中找差异，低/中/高三级难度。
- 光影/色彩判断：判断画面光源、对比度、视觉异常或氛围倾向。
- 音色分辨：分辨音色、音高、节奏或细微差别。
- 双球注意力：指定两颗小球在多个小球中移动，结束后找出目标。
- 舒尔特方格：按顺序寻找数字，测试视觉搜索与持续注意。

需要强调：

- WIS 不是“聪明”，而是察觉、判断、专注、直觉和现场感。
- 适合解释侦察、治疗、追踪、审美、危机预判、环境阅读。

### 6.6 魅力 CHA

模块：沟通交涉、人格气场、价值观表达、艺术感染力。

测试：

- 深层情境交涉：谈判、劝说、安抚、威慑、拒绝、带队。
- 价值与阵营：通过选择题判断善恶九宫格倾向。
- 人格风格：结合 MBTI 自填或选择题推断表达风格。
- 群众倾向判断：判断哪种表达更适合当前受众。

需要强调：

- CHA 不等于外向，也不等于讨人喜欢。
- 它包括影响力、表达方式、可信度、压迫感、共情、气场和舞台感。
- 内向角色也可以高魅力，例如冷静、有说服力、压迫感强或共情深。
