# 种族征召图片接入明细报告

更新时间：2026-07-08

## 接入原则

- 页面运行时只使用压缩预览图：`assets/recruitment/generated/*-preview.webp`。
- 源图只做留档与复裁：`assets/recruitment/generated/*-source.webp`，不要直接接进 UI。
- 总入口是 `data/race-recruitment-assets.js`，由 `index.html` 加载后暴露 `window.RACE_RECRUITMENT_ASSETS`。
- `assets/recruitment/image_manifest.json` 是资产台账，当前 `readyCount` 为 `29 / 29`。

## 代码读取关系

- `index.html` 加载 `data/race-recruitment-assets.js`。
- `app.js` 通过 `RACE_RECRUITMENT_ASSETS.ui` 读取通用图。
- `app.js` 通过 `RACE_RECRUITMENT_ASSETS.races[raceId]` 读取种族卡。
- `app.js` 通过 `RACE_RECRUITMENT_ASSETS.targets.troll[targetId]` 读取目标图。
- `app.js` 通过 `RACE_RECRUITMENT_ASSETS.questions[question.id]` 读取体格题图。
- `app.js` 通过 `RACE_RECRUITMENT_ASSETS.endings.troll[endingType]` 读取结局图。

## 后续生图统一规则

- 种族卡继续使用 2:3 卡牌式构图，输出 `720x1080` 的 `*-preview.webp`。
- 题目图、目标图、结局图继续使用 16:9 场景构图，输出 `1536x864` 的 `*-preview.webp`。
- 首页大厅图例外，可使用 `1920x1080` 的 `*-preview.webp`。
- 接入时只填 `file: "...-preview.webp"`，`sourceFile: "...-source.webp"` 只做档案字段。
