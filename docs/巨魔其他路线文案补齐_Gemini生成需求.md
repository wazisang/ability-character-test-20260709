## 通用题目结构

每条路线生成 7 道职业试炼题。

每道题字段：

- `id`: 英文下划线，必须唯一
- `targetId`: 必须等于对应路线 ID
- `title`: 2-8 个中文字符，像跑团章节名
- `scene`: 80-150 字，有明确地点、NPC、压力和选择后果
- `prompt`: 一句提问
- `options`: 4 个选项

每个选项字段：

- `id`: A / B / C / D
- `text`: 玩家选择文本，必须像角色行动，不像心理测验答案
- `npcReply`: NPC 反馈，30-90 字
- `branchHint`: 简短归档结果，10-28 字
- `outcomeTone`: 从以下五类选一个：
  - `合格`
  - `偏离`
  - `转岗`
  - `危险`
  - `荒诞`
- `scoreDelta`: 六维影响，范围 -2 到 +3
  - 可用键：`str / dex / con / int / wis / cha`
- `mbtiDelta`: MBTI 倾向，范围 -2 到 +2
  - 可用键：`I / E / N / S / T / F / J / P`
- `affinityDelta`: 职业志愿适配，范围 -2 到 +3
  - 可用键：`barbarian / fighter / warlock / druid`
  - 也可直接用内部 ID：`barbarian_camp / fighter_line / warlock_contract / druid_mutation_circle`
- `alignmentDelta`: 阵营/动机倾向，范围 -2 到 +2
  - 可用键：`lawful / chaotic / good / self`
- `triggerTags`: 2-4 个标签

每道题尽量让 4 个选项形成四种不同方向：

1. 本路线正解：提高本职业适配，`outcomeTone` 多为 `合格`
2. 高智商偏离：做法聪明但不属于该路线，容易转岗
3. 危险邪恶：保留黑暗奇幻强度，但不要现实冒犯
4. 荒诞奇招：桌边会笑，但仍然能写成角色行为

## 计分平衡

为了让最终公会判定稳定工作，请遵守：

- 每条路线 7 题里，至少 4 道题存在清晰的本路线合格选项。
- 合格选项通常给本路线 `affinityDelta +2` 或 `+3`。
- 偏离选项要把玩家自然导向别的路线，不要只是扣分。
- 危险选项要能触发黑名单、契约污染、军规处分或荒野失控。
- 荒诞选项可以给少量适配，但要有代价。
- 不要让单个选项出现超界数值。
- 不要让一条路线所有正解都只堆同一个属性。

建议属性重心：

- 战士前线：`con / wis / str`，少量 `cha`
- 术士契约所：`cha / con / int`，少量 `wis`
- 德鲁伊异变环：`wis / con / int`，少量 `cha`

## 路线一：战士前线

内部 ID：`fighter_line`

职业幻想：

不是“巨魔穿甲就成战士”，而是把怪物外壳锁进军纪、队形和盾墙里。

核心冲突：

- 怪物本能 vs 军团纪律
- 再生承伤 vs 阵线资源
- 大体型压迫感 vs 队友恐惧
- 会移动的城墙 vs 不是所有问题都能站桩

7 道题方向：

1. 阵线推进：号角吹响后，巨魔如何跟上盾墙节奏，而不是一个人冲出去
2. 冲击承受：面对巨兽、攻城锤或骑兵冲锋，如何把身体变成防线
3. 军令与直觉：军令要求守位，但怪物直觉闻到侧翼伏击
4. 队友恐惧：袍泽害怕你失控，你如何让他们敢站在你身后
5. 装备适配：超大号重甲、断裂扣带、窄门和楼梯让你行动受限
6. 防线选择：救后排、堵缺口、追杀敌将三者冲突
7. 最终证明：证明你不是“套上盔甲的野兽”，而是能被托付阵线的战士

战士线选项范式：

- 合格：听令、守位、用身体承担防线责任
- 偏离：用战术脑子找旁门解法，可能转工匠/术士/德鲁伊
- 转岗：过度狂暴会被丢去蛮子营地
- 危险：把队友当消耗品、故意制造恐惧、军令外私刑
- 荒诞：用巨体卡门、睡着堵路、把盾墙变成临时家具

## 路线二：术士契约所

内部 ID：`warlock_contract`

职业幻想：

不是“巨魔也能施法”这么简单，而是巨魔的再生、痛苦、血液和被厌弃的身份全都可以成为契约货币。

核心冲突：

- 你是在利用契约，还是正在被契约利用
- 再生能力是天赋，还是被宗主持续收租的矿脉
- 被文明排斥的怪物，是否会被“变回可被接纳的样子”诱惑
- 聪明交易 vs 灵魂负债

7 道题方向：

1. 血肉开价：契约所想购买你的再生秘密
2. 痛苦换力：宗主要求你用可再生的痛苦换取即时力量
3. 身份诱惑：异界存在承诺让你摆脱“怪物外壳”
4. 恶毒条款：队友发现契约文本里藏着会伤害小队的漏洞
5. 债务催收：宗主要提前收取一笔你不想支付的血肉利息
6. 禁忌知识：你发现可以用自己的再生组织复写禁书
7. 最终证明：证明你不是廉价肉器，而是能谈判、控价、反制宗主的术士

术士线选项范式：

- 合格：谈判、设限、利用代价换取可控力量
- 偏离：用理性或道德拒绝契约，可能转战士/德鲁伊
- 转岗：只想研究生命异常，可转德鲁伊异变环
- 危险：无底线抵押队友、记忆、灵魂、未来伤口
- 荒诞：用合同格式、会计逻辑或巨魔式误解反杀宗主

术士线必须有足够危险感：

- 7 道题里至少 4 道题有 `outcomeTone: "危险"` 选项。
- 危险不是现实犯罪，而是奇幻契约、灵魂债务、禁忌法术、宗主污染。
- 不要把玩家写成纯蠢肉器；即使失败，也要像一个危险角色，而不是被羞辱的工具。

## 路线三：德鲁伊异变环

内部 ID：`druid_mutation_circle`

职业幻想：

不是“巨魔回归自然”，而是荒野把巨魔再生视为一种极端生命现象：可能是恩赐，可能是污染，也可能是一种正在学习边界的共生。

核心冲突：

- 文明恐惧你，荒野未必温柔地接纳你
- 再生不是无代价恢复，而是饥饿、孢子、毒素、兽性和环境循环
- 德鲁伊不是让你变善，而是让你理解生命代价
- 你到底是守护者、污染源，还是新生态的样本

7 道题方向：

1. 林地排斥：自然灵也对你的再生感到警惕
2. 城镇与荒野：城镇拒绝你，森林愿意给你一条路
3. 饥饿控制：伤口恢复引发野性饥饿，你必须处理病患、猎物或敌人
4. 毒素共生：你的伤口长出孢子、藤蔓或毒花，如何使用它
5. 净化任务：腐化沼泽要求你用自己的再生去吸收污染
6. 保护与捕食：你要保护弱小生物，但本能把它们视作补给
7. 最终证明：证明你不是污染源，而是能理解循环、控制异变的德鲁伊

德鲁伊线选项范式：

- 合格：控制异变、理解循环、把再生纳入生态责任
- 偏离：用科学/术士方式研究自己，可能转术士
- 转岗：过度纪律化可转战士；过度狂暴可转蛮子
- 危险：放任污染、吞食禁忌、把荒野当借口伤害无辜
- 荒诞：把自己种进地里、用蘑菇开会、让伤口投票

德鲁伊线要保留怪异感：

- 可以温柔，但不能变成纯治愈系。
- 可以善良，但必须有异变、毒性、饥饿和生态代价。
- 不要把“自然”写成万能正义。

## 结局模板要求

请同步修订或补齐 `endingTemplates`，让三条路线有专属结局。

程序会按以下逻辑选择：

- `endingType`
- `recommendedClass`
- `rejectedClass`

所以每条结局模板必须保留：

- `endingId`
- `endingType`
- `title`
- `verdictLine`
- `explanation`
- `tableFunction`
- `playableFlaw`
- `nextHook`
- `recommendedClass`
- `rejectedClass`（仅转岗结局需要）
- `tags`

建议维持 20 条结局模板：

- `accepted`: 4 条，每条对应一个推荐路线
- `probation`: 4 条，每条对应一个推荐路线
- `transferred`: 4 条，覆盖常见转岗方向
- `blacklisted`: 4 条，每条对应一种失败危险
- `absurdAccepted`: 4 条，每条对应一种荒诞通过

三条路线的结局要避免套话：

- 战士录取不是“你很稳”，而是“军团愿意把防线交给这副怪物身体”
- 术士录取不是“你很邪恶”，而是“你能给自己的再生能力定价，并在宗主面前保留谈判权”
- 德鲁伊录取不是“你爱自然”，而是“你能把失控再生纳入循环，而不是把林地拖进污染”

转岗结局建议覆盖：

1. 从战士转蛮子：军纪锁不住怪物冲动
2. 从术士转德鲁伊：你更像在研究生命异变，而不是经营契约
3. 从德鲁伊转术士：你把自然循环写成了冷酷交易
4. 从蛮子或任意路线转战士：你比预期更稳，更适合作为防线核心

## MBTI 融合要求

本轮不要求生成 16 种 MBTI 全量长文，但题目、反馈和结局必须能容纳不同人格风格。

可参考四组：

- NT：精算、拆规则、谈判、研究再生机制
- NF：守护、被接纳、与怪物身份和解，但不要洗白危险
- SJ：军规、誓言、流程、承诺、守位
- SP：临场、冲动、街头解法、身体直觉、荒诞奇招

每条路线都要允许至少两种不同 MBTI 气质成立。

例如：

- 战士 + INTP：用物理杠杆和受力点理解盾墙
- 战士 + ISTJ：经年累月把怪物本能压成可靠流程
- 术士 + ENTP：把宗主契约当成可钻漏洞的辩论桌
- 术士 + INFJ：背负禁忌契约，但试图把代价导向某种使命
- 德鲁伊 + INFP：把被世人恐惧的异变写成守护誓言
- 德鲁伊 + ISTP：像解剖机关一样处理毒孢、藤蔓和再生组织
