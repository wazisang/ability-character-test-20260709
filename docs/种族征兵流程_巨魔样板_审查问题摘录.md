## 需要局部降刺激 / 避免现实冒犯的词

这些词不是全部禁止，但当前语境里容易从奇幻吐槽滑到现实冒犯、精神疾病污名或角色降格。请保持巨魔的危险感和黑色幽默，但换成奇幻语境。

### 1. “神经病 / 疯病”

位置：

- `barbarian_narrow_defense` 某选项 `branchHint`: “通过但会被视为神经病”
- `barbarian_friendly_fire` 某选项 `branchHint`: “通过但被当成神经病”
- `warlock_dirty_clause` 某选项 `npcReply`: “神经病举动”“疯病”
- `troll_transferred_smart.explanation`: “此怪脑子有病”

问题：

现实精神疾病污名化，和项目里“降低刺激性”的要求冲突。

建议替换方向：

- “被视为营地怪谈”
- “被记录为高危奇招”
- “被列入异常行为档案”
- “此怪思路过于危险，建议送去施法者那边”

### 2. “宠物养 / 团宠 / 军团宠物”

位置：

- `troll_absurd_mascot.verdictLine`: “决定把你当宠物养”
- `troll_absurd_mascot.explanation`: “最庞大、最暴力的‘团宠’”
- `troll_absurd_mascot.tags`: “军团宠物”

问题：

会把角色从“荒诞通过”降格成被饲养对象，破坏玩家角色尊严。

建议替换方向：

- “营地吉祥物”
- “编外招牌”
- “被老兵联名保下的危险新人”
- “营地最吓人的活招牌”

### 3. “无智工程锤”

位置：

- `troll_blacklisted_weapon.title`: “无智工程锤”
- `verdictLine`: “连最基本的交流都无法完成，他们决定把你当成攻城兵器卖掉。”

问题：

过于低智羞辱，且“卖掉”会让黑名单结局从奇幻危险变成对玩家角色的物化处理。

建议替换方向：

- 标题：“失控攻城锤”
- 判定：“公会拒绝录用，但某些攻城承包商已经盯上了你的破坏力。”
- 保留危险路线，不要写成角色被当物品交易。

### 4. “正常人 / 丑陋”

## 分支设计建议

### 术士题组缺少“危险”tone

当前 `warlock_contract` 四道题的选项 tone 分布：

- 合格
- 偏离
- 转岗
- 荒诞

没有 `危险`。

问题：

术士契约线本应最适合“危险交易 / 黑名单 / 被宗主盯上”的分支。没有危险 tone 会削弱契约试炼的风险。

建议：

把每道术士题至少一个选项改成 `outcomeTone: "危险"`，尤其是：

- 出卖再生秘密
- 用痛苦换力量
- 接受人类皮囊诱惑
- 契约漏洞处理

不要增加题目，只改选项 tone 和 branchHint 即可。

### 部分非蛮子试炼每题不是四类型齐全

需求里要求每题 4 选项尽量对应：

1. 职业正解
2. 高智商偏离
3. 危险邪恶
4. 荒诞奇招

当前战士、术士、德鲁伊轻量题组里，有些题出现两个“合格”或没有“危险”。

建议：

不用大改，只需要保证每个职业题组整体有：

- 稳定合格路线
- 聪明但偏离路线
- 危险/黑名单路线
- 荒诞但可成角色路线
