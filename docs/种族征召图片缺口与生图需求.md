## 统一风格基线

后续新增图片必须复用本轮已验证的视觉基线：

- 横向 16:9 公会档案卡，不做竖版个人 CG。
- 暗铜装饰边框、黑铁与旧木、羊皮纸、低饱和厚涂写实。
- 环境至少占画面三分之二，角色不超过三分之一。
- 必须能看见职业空间、工具、档案、徽记或训练设施。
- 光线以火把、蜡烛、月光和受控魔法光为主，禁止霓虹和赛博朋克。
- 网页接入用的 `*-preview.webp` 采用自适应中间调提亮，目标平均亮度约 55；`*-source.webp` 保留原始生成结果。
- 禁止文字、水印、Logo、现代 UI、动漫、Q 版、近景头像和过度性感化。
- 半身人必须是成年角色，禁止儿童、少年和幼态脸。
- 每张提示词同时包含种族锚点和职业锚点，抓图时也用两者组合匹配任务卡。

## 后续生成与审查顺序

1. 一次只生成一张，完成抓取、压缩和清单更新后再提交下一张。
2. 每完成一个种族，四张并排检查种族锚点、边框、色调和人物比例。
3. 拒绝近景个人 CG、普通人类替代、幼态半身人、种族特征丢失和职业场景不可读的结果。
4. 图片接入后验证清单、文件存在性、JS 语法、浏览器图片请求和实际 UI 裁切。
5. 在项目深色背景中复核亮度；极暗室内图应提升中间调，但保留黑位、边框和局部光源对比。
